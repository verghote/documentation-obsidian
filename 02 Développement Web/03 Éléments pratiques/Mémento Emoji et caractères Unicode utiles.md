# Introduction

Les caractères Unicode permettent d'ajouter des repères visuels dans les documentations,
les fichiers Markdown, les interfaces ou les commentaires de code.

Format général : 
```
U+XXXX
```

Exemple :
```
↓ = U+2193
```


# Opérations sur les données

Les symboles suivants peuvent être utilisés pour représenter les principales opérations effectuées sur des données : création, lecture, modification, suppression, recherche, filtrage, tri, importation, exportation et actualisation.

## Recherche et filtrage

|Symbole|Nom|Code Unicode|Opération|Usage|
|---|---|---|---|---|
|🔍|Loupe|U+1F50D|**Recherche**|Rechercher une donnée|
|🔎|Loupe inclinée|U+1F50E|**Recherche détaillée**|Recherche avancée|
|🔍➕|Loupe +|U+1F50D + U+2795|**Recherche avancée**|Ajouter un critère|
|🔍➖|Loupe −|U+1F50D + U+2796|**Recherche avancée**|Retirer un critère|
|⚱️|Filtre|U+26B1|**Filtrage**|Symbole alternatif de filtre|

|⋮|Menu vertical|U+22EE|**Options**|Menu contextuel|
|⋯|Menu horizontal|U+22EF|**Options**|Actions supplémentaires|

> **Remarque :** il n'existe pas de symbole Unicode universel spécifiquement dédié à l'opération « filtre ». Pour une interface, le symbole d'entonnoir **🔽** ou, mieux encore, une icône provenant d'une bibliothèque d'icônes, est généralement plus explicite.
