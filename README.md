# Documentation SLAM

Ce dépôt est un coffre [Obsidian](https://obsidian.md/) qui rassemble des supports de cours, des notes techniques et des ressources de veille autour du développement d'applications et de la cybersécurité.

Ce dépôt évolue régulièrement en fonction de l'avancée dans la formation
Une fois installée sur votre poste de travail, il vous appartient de récupérer la dernière version depuis https://github.com/verghote/documentation-obsidian
Pour cela il vous faut supprimer votre version locale et récupérer la version sur GitHub


## Contenu

## Utilisation avec Obsidian

Ouvrez ce dossier comme coffre Obsidian (`Open folder as vault`). Les notes sont des fichiers Markdown ; les modifications apportées dans Obsidian sont enregistrées directement dans les fichiers du coffre.
