# Avant 2022 : l'IA comme outil spécialisé

Pendant des décennies, l'intelligence artificielle reste principalement un ensemble de technologies spécialisées : moteurs de recommandation, reconnaissance d'images, traduction automatique ou assistants vocaux. Les développeurs, ingénieurs, journalistes ou créateurs continuent de produire eux-mêmes l'essentiel du contenu et des logiciels. L'IA assiste, mais ne remplace pas les activités intellectuelles.

# 2022 : la démocratisation des grands modèles de langage

L'arrivée des grands modèles conversationnels marque une rupture. Pour la première fois, le grand public peut dialoguer avec une IA capable de rédiger des textes, expliquer des concepts, produire du code ou répondre à des questions complexes.

Les premiers systèmes impressionnent par leur capacité à converser mais restent limités : erreurs fréquentes, hallucinations, absence de connaissances récentes et qualité variable des réponses. Beaucoup les considèrent alors comme des démonstrations technologiques prometteuses mais encore immatures.

# 2023-2024 : l'IA devient réellement productive

Les modèles progressent rapidement grâce à l'augmentation de leur puissance de calcul, de leurs données d'entraînement et à leur connexion au web.

Plusieurs évolutions majeures apparaissent :

- génération de code de meilleure qualité ;
- intégration dans les environnements de développement ;
- accès à des informations en temps réel ;
- apparition des modèles multimodaux capables de comprendre texte, image, audio et vidéo.

L'IA commence alors à devenir un véritable outil de travail quotidien pour de nombreux professionnels.

Dans le même temps émergent les premières externalités négatives :

- aspiration massive des contenus du web pour l'entraînement des modèles ;
- augmentation du trafic automatisé sur Internet ;
- explosion des contenus synthétiques ;
- multiplication des faux contenus, deepfakes et campagnes de désinformation.

# 2025 : le basculement vers l'IA agentique

L'année 2025 constitue un tournant.

Les modèles ne se contentent plus de répondre à des questions. Ils deviennent capables d'agir à travers des outils externes :

- exécution de commandes ;
- consultation de bases de données ;
- interaction avec des applications ;
- génération complète de fonctionnalités logicielles.

Les assistants de programmation franchissent un cap important. Ils produisent non seulement du code mais également des tests, de la documentation et des architectures complètes.

On entre alors dans l’ère de l’**IA agentique**, où les systèmes deviennent capables d’exécuter de manière relativement autonome des chaînes d’actions nécessaires au développement logiciel.

Le **goulot d’étranglement du développement logiciel se déplace**. Historiquement, le développement était principalement contraint par la capacité des développeurs à **produire du code**. Le code constituait donc une ressource relativement « rare ».

Avec l’intégration des agents IA, la génération de code devient beaucoup moins coûteuse et beaucoup plus rapide. La problématique évolue alors : nous passons de **« Comment produire suffisamment de code ? »** à **« Comment vérifier, contrôler et intégrer suffisamment rapidement le code produit ? »**.

Cette évolution transforme également le cycle de développement. On passe progressivement d’une procédure principalement séquentielle :

**Planification → Développement → Test → Review → Déploiement**

à un processus davantage **itératif et automatisé** :

**Intention → Génération → Build → Test → Validation → Review → Correction → Re-test → …**

L’agent peut ainsi enchaîner plusieurs étapes du cycle et **itérer automatiquement** jusqu’à produire une modification respectant les contraintes et critères de validation définis.

Le rôle du développeur évolue donc lui aussi : il ne se limite plus à produire directement le code, mais consiste davantage à **définir l’intention, les contraintes et les critères de validation, puis à superviser et contrôler le travail réalisé par les agents**.
# 2025-2026 : la généralisation dans les entreprises

L'IA cesse d'être un outil réservé aux technophiles.

Les entreprises l'intègrent dans :

- le développement logiciel ;
- le support client ;
- la finance ;
- le marketing ;
- la création de contenu ;
- les ressources humaines.

Les métiers évoluent progressivement. Une partie du travail de production est automatisée tandis que les humains se concentrent davantage sur la supervision, la validation et le contrôle qualité.

Cette période voit également émerger de nouvelles interrogations économiques :

- coût réel de l'inférence à grande échelle ;
- rentabilité des modèles ;
- dépendance à quelques grands fournisseurs ;
- transformation du marché de l'emploi.

# Les conséquences sur l'écosystème numérique

La montée en puissance de l'IA entraîne une demande gigantesque en infrastructures.

Les besoins explosent en :

- processeurs spécialisés ;
- mémoire ;
- stockage ;
- énergie ;
- centres de données.

Les investissements se chiffrent en dizaines de milliards d'euros et de dollars. La consommation énergétique des futurs centres de calcul devient un sujet majeur, tout comme leur consommation d'eau pour le refroidissement.

Parallèlement, les communautés open source et les acteurs du web s'interrogent sur la soutenabilité d'un modèle où les contenus produits par les humains servent à alimenter des systèmes automatisés qui finissent par concurrencer leurs propres créateurs.
# Le défi actuel : préserver la connaissance humaine

La question centrale n'est plus uniquement technique.

L'enjeu devient de savoir comment utiliser l'IA sans perdre les compétences humaines qui ont permis de construire le numérique moderne.

Les gains de productivité sont réels, mais ils s'accompagnent de nouveaux risques :

- dépendance cognitive ;
- perte de savoir-faire ;
- diminution de l'esprit critique ;
- difficulté à distinguer information et connaissance.

L'histoire récente de l'IA peut ainsi être lue comme le passage d'un simple outil d'assistance à une technologie capable de produire, décider et agir. La prochaine étape ne dépendra probablement plus seulement des progrès techniques, mais des choix que feront les organisations et les individus quant à la place qu'ils souhaitent lui accorder dans leur travail et dans leur vie quotidienne.

# Le rôle de l'humain change

L'humain ne disparaît pas du cycle ; **il monte d'un niveau d'abstraction**.

|Avant les agents IA|Avec les agents IA|
|---|---|
|Écrire le code|Définir l'intention|
|Implémenter|Diriger les agents|
|Corriger les bugs|Définir les contraintes|
|Faire une partie des tests manuellement|Superviser la validation|
|Faire les reviews ligne par ligne|Examiner les exceptions et décisions importantes|
|Gérer les tâches techniques|Se concentrer sur architecture, produit et arbitrages|
