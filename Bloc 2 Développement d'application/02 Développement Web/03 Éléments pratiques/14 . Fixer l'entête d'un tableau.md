
Il faut ajouter un conteneur autour du tableau (par exemple `<div class="table-container">`) pour isoler la zone de défilement.

```
<div class="table-container"> 
	<table> 
		<thead> 
			<tr> 
				<th>Étudiant</th> 
				<th style="text-align:center;">Inscrit Le</th> <th style="text-align:center;">Relancé Le</th> <th>État</th> <th>Édition des courriers</th> 
			</tr> 
		</thead> 
		<tbody id="lesLignes"></tbody> 
	</table> 
</div>
```

Il faut ajouter les règles suivantes dans la feuille de style

```css
/* Conteneur avec défilement vertical */
.table-container {
    max-height: 450px; /* Hauteur maximale avant apparition du scroll */
    overflow-y: auto;  /* Active la barre de défilement si le tableau dépasse */
    border: 1px solid #dee2e6;
    border-radius: 4px;
}

/* Fixation de l'en-tête */
.table-container table thead th {
    position: sticky;
    top: 0;
    z-index: 2; /* S'assure que l'en-tête reste au-dessus des lignes */
    background-color: #f8f9fa; /* Fond opaque obligatoire pour masquer le texte qui défile dessous */
    box-shadow: inset 0 -1px 0 #dee2e6; /* Remplace la bordure inférieure pour éviter les sauts au défilement */
}
```

Attention :  
`position: sticky` retire l'en-tête du flux normal lors du défilement. 
Si aucun fond explicite n'est défini sur les `th`, le fond devient transparent et les lignes du tableau se voient en arrière-plan à travers l'en-tête.

Une valeur fixe comme `max-height: 450px` ne remplit pas l'écran. Il faut utiliser une unité relative à la fenêtre d'affichage (`vh`) combinée avec la fonction CSS `calc()`.

```css
/* 1. Le conteneur occupe toute la hauteur disponible jusqu'au bas de l'écran */
.table-container {
    /* 100vh = toute la hauteur de l'écran, moins la hauteur estimée du header/titres (~200px) */
    max-height: calc(100vh - 200px); 
    overflow-y: auto;
    border: 1px solid #dee2e6;
    border-radius: 4px;
}

/* 2. Fixation et restauration de la couleur de fond de l'en-tête */
.table-container table thead th {
    position: sticky;
    top: 0;
    z-index: 10;
    
    /* Applique la couleur de fond de ton thème (ex: bleu sombre, gris ou couleur personnalisée) */
    background-color: #343a40; /* <- Remplace par la couleur de ton thème d'origine */
    color: #ffffff;            /* Couleur du texte si le fond est sombre */
    
    /* Conserve la bordure basse lors du scroll sticky */
    box-shadow: inset 0 -2px 0 #212529; 
}
```
