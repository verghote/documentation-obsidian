Les caractères Unicode permettent d'ajouter des repères visuels dans les documentations, les fichiers Markdown, les interfaces ou les commentaires de code.

**Format général :** `U+XXXX`

_Exemple :_ `↓` = `U+2193`

## Synthèse Récapitulative (Recommandée pour Interface)

Pour garantir la cohérence visuelle d'une application de gestion, voici une convention standard d'icônes recommandées :

|**Opération**|**Symbole**|
|---|---|
|**Créer / Ajouter**|➕|

|**Rechercher**|🔍|
|**Filtrer**|🔽|
|**Modifier**|✏️|
|**Actualiser**|🔄|
|**Supprimer**|🗑️|
|**Valider**|✅|
|**Annuler**|❌|
|**Enregistrer**|💾|
|**Importer**|📥|
|**Exporter**|📤|
|**Tri croissant**|▲ / ↑|
|**Tri décroissant**|▼ / ↓|
