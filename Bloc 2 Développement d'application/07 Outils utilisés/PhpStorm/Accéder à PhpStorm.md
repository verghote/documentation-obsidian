
Ce document explique comment activer et utiliser **PhpStorm** dans le cadre de la formation.

Deux solutions sont possibles :

1. Utiliser la **licence serveur du lycée** (méthode recommandée).
2. Utiliser une **licence étudiante gratuite JetBrains** obtenue via GitHub Education (méthode alternative).
# Prérequis

- Disposer d'une adresse électronique fournie par le lycée : prenom.nom@saint-remi.net
- Posséder un compte JetBrains (gratuit).
- Avoir installé PhpStorm sur son ordinateur.
# Méthode 1 - Utiliser la licence serveur du lycée (recommandée)

Le lycée met à disposition une **licence serveur JetBrains** accessible à tous les étudiants.

Serveur de licences :

```text
https://saintremi.fls.jetbrains.com
```

## Étape 1 - Créer un compte JetBrains

Si vous ne possédez pas encore de compte JetBrains :

- rendez-vous sur le site JetBrains ;
- créez un compte en utilisant votre adresse du lycée : prenom.nom@saint-remi.net

Une fois le compte créé, confirmez votre adresse électronique.
## Étape 2 - Ouvrir PhpStorm

Lancer PhpStorm.

Lors du premier démarrage, une fenêtre d'activation de la licence apparaît.

Choisir :

```text
License Server
```

## Étape 3 - Saisir le serveur de licences

Entrer l'adresse suivante :

```text
https://saintremi.fls.jetbrains.com
```

Valider.

Si votre compte est autorisé, PhpStorm s'active automatiquement.

# Méthode 2 - Obtenir une licence étudiante gratuite JetBrains

JetBrains met gratuitement l'ensemble de ses IDE à disposition des étudiants via son programme **Student Pack**.

Cette solution est particulièrement utile pour travailler sur un ordinateur personnel en dehors du lycée.

## Prérequis

- Posséder u compte GitHub.
- Être éligible à GitHub Education.
- Posséder un compte JetBrains.

## Étape 1 - Obtenir GitHub Education

Créer un compte GitHub si nécessaire.

Faire ensuite une demande d'accès au **GitHub Student Developer Pack**.

La validation peut nécessiter quelques jours.

## Étape 2 - Activer la licence JetBrains

Une fois GitHub Education obtenu :

- se connecter à son compte JetBrains ;
- associer son compte GitHub ;
- demander l'activation de la licence étudiante.

Après validation, la licence JetBrains est automatiquement associée au compte.

## Étape 3 - Se connecter dans PhpStorm

Au lancement de PhpStorm :

Choisir :

```text
JetBrains Account
```

Puis se connecter avec le compte JetBrains ayant obtenu la licence.

L'IDE s'active automatiquement.

# Vérifier l'activation

Dans PhpStorm :

```text
Help → Register...
```

La fenêtre indique :

- le type de licence utilisée ;
- sa date d'expiration éventuelle ;
- le compte JetBrains associé.

# Quelle méthode choisir ?

Pour les travaux réalisés dans le cadre de la formation, il est recommandé d'utiliser la **licence serveur du lycée**.

La licence étudiante JetBrains constitue une excellente alternative pour travailler sur un ordinateur personnel ou poursuivre ses projets en dehors de l'établissement.

Les deux solutions sont compatibles avec les mêmes versions de PhpStorm et permettent d'accéder à l'ensemble des fonctionnalités professionnelles de l'IDE.
